\f0\b\fs48 \cf0 How To Install GiveMiiFont\

\fs24 GiveMiiFont is a small project, and it\'92s easy to set up.\
\
What you will need:\
A Wii U\
SD Card (anywhere from 8GB to 32GB is the recommended type for Wii U Aroma modding)\
SD Card (Adapter) (or a FTP Server from GitHub or HB Appstore (I prefer to use FileZilla))\
\
\cf2 Please Note: GiveMiiFont will not tamper with your NAND in any way to prevent a console brick.\
Also Note: GiveMiiFont may glitch out at times, if so, power off your Wii U, and power it on, that should reset your font, you can disable it if you wish.\
Im being serious, Last Note: Not every single app will work with GiveMiiFont. during a test, GiveMiiFont was unable to load an app, and froze the Wii U. if that happens to you, hold the power button for 4-5 seconds, and power the console back on.\cf0 \
\
For FTP Users:\
Download FTPiiU (Anywhere)\
Set up your FTP Server and connect to your computer.\
In /fs/vol/external01/wiiu/  You will need to create a directory called \'93fonts\'94\
Once you have created fonts, you can look for environments in wiiu and go to this directory:\
/fs/vol/external01/wiiu/environments/aroma/plugins/  And place your givemiifont.wps in there.\
In /fs/vol/external01/wiiu/apps/  You can make a folder named \'93GiveMiiFont\'94 and place \'93givemiifont.wuhb\'94 in there\
Once you are done, reboot your Wii U, look for GiveMiiFont, and open it.\
(BEFORE REBOOTING: Place a ttf file in /fs/vol/external01/wiiu/fonts, if you don\'92t have one, scroll all the way to the bottom to find some suggested sites for ttf files.)\
\
For SD Card (Adapter) Users:\
Open up your Finder (or File Explorer) and go to wiiu/environments/aroma/plugins/  And place \'93givemiifont.wps\'94 and while you are inside wiiu, create a folder named \'93fonts\'94\
Go to wiiu/apps  and create a folder named \'93GiveMiiFont\'94 and place \'93givemiifont.wuhb\'94 in there\
Reboot your Wii U, find GiveMiiFont, and open it\
